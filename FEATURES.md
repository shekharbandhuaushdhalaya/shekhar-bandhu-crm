# Feature Implementation Roadmap

## Core CRM
- [ ] Email integration (sending, templates, IMAP sync)
- [ ] Calendar / scheduling
- [ ] Automated workflows (drip campaigns, lead nurturing)
- [ ] Customer portal / self-service
- [ ] Bulk import/export (CSV/Excel)

## Financial
- [ ] Full accounting (chart of accounts, P&L, balance sheet)
- [ ] GST returns data export (GSTR-1, GSTR-3B)
- [ ] Credit / debit notes
- [ ] Recurring invoices / subscriptions
- [ ] TDS / TCS calculations
- [ ] Bank reconciliation

## Inventory
- [ ] Barcode / QR code scanning
- [ ] Low stock alerts / reorder notifications
- [ ] Physical stocktake
- [ ] Expiry alerts for finished goods

## Operational
- [ ] Production planning / scheduling
- [ ] Logistics / shipment tracking API integration
- [ ] Purchase order management (separate from invoices)

## System
- [ ] Password reset / forgot password flow
- [ ] In-app notifications
- [ ] API documentation (Swagger / OpenAPI)
- [ ] Backup / restore
- [ ] Multi-language support
